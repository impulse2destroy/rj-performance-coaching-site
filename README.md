# Rhys Jones Performance Coaching: website

Single-page static site. No build step, no dependencies.

## Preview locally
Open `index.html` in any browser.

## Deploy
- Netlify Drop: drag this folder onto app.netlify.com/drop
- Cloudflare Pages or GitHub Pages: point at the `main` branch, root folder
